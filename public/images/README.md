# Website image assets

The following files are temporary visual placeholders copied from the project's bundled demo artwork:

- `campus.jpg` — replace with your own real GCWUS campus/building photograph.
- `computer-lab.jpg` — replace with a real department computer-lab photograph.
- `research-lab.jpg` — replace with a real research/lab photograph.
- `fyp-expo.jpg` — replace with a real student project/event photograph.
- `university-logo.png` — add the official university logo here when you have it.
- `teacher-1.jpg` through `teacher-10.jpg` — add each teacher's own approved photograph using the matching filename.

Use the same filenames to replace an image without changing the React code. The bundled campus/lab/event artwork is illustrative and is not verified as an authentic GCWUS photograph. Faculty cards show initials until real faculty photos are added.
