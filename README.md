# GCWUS Computer Science Department Website

A modern, responsive website concept for the Computer Science Department of Government College Women University Sialkot (GCWUS), developed as part of a Human-Computer Interaction (HCI) lab assignment.

The project explores how academic information can be presented through a clean interface, organized navigation, and user-friendly design.

> **Disclaimer:** This is an academic website concept created for educational purposes. It is not an official or university-approved GCWUS website.

## Overview

The website concept brings important departmental information together in one place. It focuses on visual organization, responsive layouts, and usability to explore how students and visitors might interact with an academic department website.

## Features

- **Responsive Design:** Layout designed to adapt to different screen sizes.
- **Navigation:** Organized navigation for exploring website sections.
- **Department Information:** Dedicated areas for academic and departmental content.
- **Academic Programs:** Sections for presenting degree programs and academic information.
- **Faculty Profiles:** Faculty information presented in a structured layout.
- **Research and Events:** Sections for showcasing research activities and departmental events.
- **Interactive Elements:** Interface elements designed to support user interaction and feedback.
- **Visual Hierarchy:** Consistent spacing, typography, colors, and content organization.
- **HCI-Focused Design:** Attention to usability, accessibility considerations, and user experience.

*Note: Features and sections are part of an academic concept; their actual functionality depends on the implemented code.*

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/AyeshaBatoolCS/gcwus-cs-department-website.git
   ```

2. Open the project folder:

   ```bash
   cd gcwus-cs-department-website
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   `http://localhost:5173`

### Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
